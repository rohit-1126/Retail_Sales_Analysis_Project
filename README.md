# Retail_Sales_Analysis_Project

# Overview
This project analyzes the Retail_Sales database using SQL to generate business insights related to sales performance, 
customer behavior, and product analysis using

---

# This Project Demonstrates :

- SQL SELECT statements
- Filtering using WHERE
- Aggregate functions (SUM, AVG, COUNT, MIN, MAX)
- GROUP BY and HAVING
- SQL JOIN operations
- Subqueries
- Window Functions

---

## Tools Used
- MySQL
- MySQL Workbench
- Excel

---

## Functional Requirements

### Basic Data Exploration
- Retrieve product records
- Filter products based on price
- Find customers from Germany

### SQL Functions & Aggregations
- Total orders placed
- Average product price
- Total revenue generated

### Join Operations
- Product category analysis
- Customer order analysis
- Employee sales analysis

### Subqueries
- Products above average price
- Customers with more than 5 orders
- Products never ordered

### Window Functions
- Product ranking by category
- Running total revenue
- Customer revenue ranking

### Advanced Analysis
- Highest revenue category
- Top customer by orders
- Employee handling most orders
