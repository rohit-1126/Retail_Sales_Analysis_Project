# 

## **Problem Statement: Sales Performance Analysis using Retail\_Sales Database**

Task is to analyze sales performance, customer behavior, and product insights using **advanced SQL techniques**.

---

# Project Task

## A) Basic Data Exploration

A.1 Retrieve all records from the **Product** table.

A.2 Display product names and unit prices for products costing more than **$50**.

A.3 List all customers located in **Germany**.

# B) SQL Functions & Aggregations

Use SQL aggregate functions to answer the following:

B.1 Calculate the **total number of orders** placed.

B.2 Find the **average unit price of all products**.

B.3 Determine the **total revenue generated**.

**\[Hint: Revenue \=  `UnitPrice × Quantity × (1 - Discount)]`**

# C) Join Operations

### C.1 Product Category Analysis

Display:

* Product Name

* Category Name

* Unit Price

Tables involved:

* Product

* Category

### C.2 Customer Order Analysis

Display:

* Customer Company Name

* Order ID

* Order Date

Tables involved:

* Customer

* SalesOrder

### C.3 Sales Performance by Employee

Display:

* Employee Name

* Order ID

* Customer Name

Tables involved:

* Employee

* SalesOrder

* Customer

# D) Subqueries

Use subqueries to answer the following:

D.1 Find products whose **unit price is higher than the average price of all products**.

D.2 Retrieve customers who have placed **more than 5 orders**.

D.3 Identify products that **have never been ordered**.

# E) Window Functions

Use window functions to perform analytical queries.

### E.1 Rank Products by Price

Rank products based on their **unit price within each category**.

### E.2 Running Total of Sales

Calculate the running total of revenue by order date.

Expected columns:

* Order Date  
* Order Revenue  
* Running Total Revenue

### E.3 Top Customers by Revenue

Calculate total revenue generated by each customer and assign a rank.

Expected output:

* Customer Name  
* Total Revenue  
* Customer Rank

# F) Advanced Analytical Queries

Write SQL queries to answer the following business questions:

F.1 **Which product category generates the highest revenue?**

F.2 **Which customer has placed the most orders?**

F.3 **Which employee handles the highest number of orders?**

---

# Objective

Use SQL queries to:

* Explore and analyze relational data

* Apply **SQL functions and aggregations**

* Use **joins to combine multiple tables**

* Implement **subqueries and window functions**

* Generate meaningful business insights from transactional data
